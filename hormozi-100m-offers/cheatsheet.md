# Cheatsheet — $100M Offers

## The one-liner test
"Would a prospect feel stupid saying no?" If no → the offer isn't done.

## Value Equation audit (score any offer)
| Lever | Ask | Move |
|---|---|---|
| Dream Outcome ↑ | Does the copy state THEIR destination? | Sell the vacation, not the flight |
| Likelihood ↑ | What proof/guarantee makes them believe? | Portfolio, numbers, named guarantee |
| Time Delay ↓ | How fast is first visible win? | Sprint format, day-1 milestones |
| Effort ↓ | What does the client have to do? | Answer should be ~"approve things" |

Bottom half beats top half: faster+easier outsells bigger claims.

## Offer build pipeline (once per product)
Dream Outcome → problem list (walk full journey, 30+ problems) → solution statements ("How to X so that Y") → vehicles (DIY/DWY/DFY × 1:1/group/1-many × medium × speed; 10x–1/10th test) → trim (kill high-cost/low-value, then low-cost/low-value) → stack (name everything, price everything).

## Enhancers checklist
- [ ] Scarcity: real capacity cap, published fill %, announced sell-outs
- [ ] Urgency: dated promo window, cohort kickoff dates, pre-announced price rises
- [ ] Bonuses: ≥3 named bonuses, each killing one objection, total stated value > core price
- [ ] Guarantee: type chosen by ticket size, conditions = success actions, memorable name
- [ ] Name: M(agnet) A(vatar) G(oal) I(nterval) C(container), 3-5 components

## Guarantee picker
Cheap+B2C → unconditional | Services → conditional/delayed-payment | Expensive custom → service guarantee or anti-guarantee | Trackable results → performance/revshare | Any ticket → stack short-unconditional + long-conditional.
Math gate: extra closes × price > incremental refunds × price, else adjust.

## Never-do list
- Never discount the core offer — add bonuses instead.
- Never fake scarcity/deadlines (resetting timers).
- Never switch niches after one failed offer.
- Never price by copying broke competitors.
- Never change a converting bundle's guts when only the creative fatigued.

## Fatigue ladder (in order)
creative → ad copy → headline/name → duration → free/discount enhancer → monetization structure.

## Local Agency pocket version
Offer: "[Avatar] [Goal] Sprint — live website in 7 days, guaranteed, or we work free." Cap slots below capacity · publish fill % · stack 4-5 zero-marginal-cost bonuses · rotate seasonal wrapper monthly · anchor price to patient/project value, never freelancer rates.
